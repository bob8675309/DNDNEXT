## Newly discovered cross-consumer release blocker and narrow draft correction

The full current-main consumer audit found `components/PlayerCharacterProfilePanelUnified.js` still used a fallback `characterSelectColumns()` requesting `background,motivation,quirk,mannerism,voice`. Stage-two `REVOKE SELECT` applies to all `authenticated` callers, including Admins, so those fallback queries would fail with permission errors after the privacy migration. **This is a concrete cross-feature compatibility defect absent from the original #320–#323 test set.**
