# Repeatable Origin feat acquisition

This disposable experiment augments the 20 accepted cases on the isolated I2J branch. It exercises the historical signed editor advancement transaction with both original spell indexes enabled. The original Lessons of the First Ones schema uses `distinctPerRepeat` with the child catalog ID. Two fixture-only Magic Initiate IDs with the same visible name let the test observe downstream source ownership while retaining this discriminator. They model catalog variants for research. Canonical same-ID requests are also exercised and remain subject to the original guard.

Magic Initiate's repeat rule requires a different spell list each time. The matrix distinguishes this rule from what the historical caller and materializer enforce.
