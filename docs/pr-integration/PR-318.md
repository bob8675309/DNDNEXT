- Additive informational GM notices originate from the existing committed player_character_created event; no GM approval gate, duplicate event producer or change to shared Forge creation. New private per-Admin reviewed receipt table and two Admin-only RPCs provide safe event projection, individual unread counts and idempotent review.
- The /admin/activity dashboard adds notices and a /npcs?focus=npc:<id> deep link, while retaining visitor/account activity. The link must resolve hidden player-created character for GM without sharing their private sheet or event details.
- New AdminCharacterPermissionsPanel in /npcs edits existing can_edit, can_inventory and can_convert flags, checks old values in UPDATE to reject conflicting Admin writes, preserves disabled all-false grant rows, and never grants the new can_control right implicitly.
- Dedicated PostgreSQL17 ACL/idempotency/concurrency fixtures, genuine GoTrue JWT tests, source validators and Next build workflow are preservation assets.
